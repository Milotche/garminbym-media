# Miss Chiang — pools de phrases (v1, anglais)

Règles : ≤ 60 caractères, ton sec et direct, pas d'accent écrit, pas de référence ethnique, pas de remarque sur le
corps. Elle est stricte, pas cruelle. Une ligne = une phrase. Le script d'import lit ce fichier tel quel : chaque
section `## pool` devient un tableau `<jsonData id="phr_<pool>">` dans `resources/strings/phrases.xml`. Les lignes qui
ne commencent pas par `- ` sont ignorées.
